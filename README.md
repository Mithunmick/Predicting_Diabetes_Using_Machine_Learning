# Predicting_Diabetes_Using_Machine_Learning
Predicting Diabetes Using Machine Learning
Master’s Project – DTU, Course: Project in Intelligent Systems (34367)
January 2024

Developed a predictive model for early-stage diabetes detection using Electronic Health Records (EHRs).

Conducted extensive exploratory data analysis (EDA) and feature engineering on a dataset of 10,000 patients.

Addressed data imbalance using SMOTE (Synthetic Minority Oversampling Technique) to improve model robustness.

Implemented and evaluated four ML classifiers: Random Forest, Decision Tree, K-Nearest Neighbors, and Extra Trees.

Achieved 99% accuracy with the Random Forest model on balanced data.

Tools & Technologies: Python, Pandas, Scikit-learn, Matplotlib, Seaborn.
